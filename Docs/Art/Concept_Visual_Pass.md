# Concept visual pass

Reference: supplied Afterfall Raiders and Rigs concept board. Start with B, the gunship: two lateral ducted fans, compact armored body, recessed orange sensor, two forward weapon pods. C remains the separate bomber design.

Run the gunship script in Blender's Text Editor in Object Mode. It creates its own collection and replaces only its tagged output on rerun. Rotor pivots are separate and animate on frames 1–120. No scene-wide deletion or automatic save.

The HOUND V04 script is standalone and replaces the earlier tagged HOUND output. It preserves the nine logical parts and six sockets while refining the geometry and finish. Procedural materials need baking before Unreal import.

These are modeled interpretations of a single concept board, not an exact reconstructed production asset. Review silhouette and proportions in Blender before accepting final art. Gameplay code is unchanged.
