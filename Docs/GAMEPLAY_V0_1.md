# Gameplay V0.1

## Core test loop

1. Spawn in a small underground staging room.
2. Choose the starter loadout.
3. Deploy into the Deadwater Basin prototype.
4. Find scrap, electronics and a machine component.
5. Encounter a Scout/Tracker patrol.
6. Encounter one Leaper in a marked danger area.
7. Optional: approach a Bastion-controlled high-value zone.
8. Reach one of two extraction points.
9. Hold extraction for 8 seconds while remaining alive.
10. Return to the staging room with extracted loot.

If the player dies before extraction, carried raid loot is lost.

## V0.1 map target

The first map is not an open world. Use a compact 600 m–900 m playable combat space with sightline blockers and three distinct points of interest:

- **Dry Relay Station** — low-risk starter loot.
- **Collapsed Mine Yard** — Leaper territory / medium-value tech.
- **Solar Graveyard** — Bastion high-risk/high-value zone.

Two extractions sit on opposite edges of the map so route choice matters.

## Combat principles

- Weak points should matter more than raw health bars.
- Machines must telegraph dangerous attacks.
- Large attacks need readable mobile-screen warnings.
- The player should understand why they died.
- Avoid bullet-sponge enemies.
- Sound is gameplay: machine movement, charging weapons and detection cues matter.

## First success criterion

The prototype is ready for expansion only when this 5-minute loop feels good:

**move → aim → shoot → evade Leaper → destroy weak point → loot → extract**
